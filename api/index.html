Sunset Score API

Add sunrise and sunset quality forecasts to your app, travel experience, or agent. Send coordinates. Get a score from 0 to 100.

For your own sunrise and sunset forecasts, you can use the Sunset Score mobile app.

Your first forecast

Copy this command into your terminal to request a three-day forecast in Chicago.

TERMINAL · CHICAGO
curl --fail-with-body --show-error \
  --connect-timeout 10 --max-time 60 \
  --get 'https://api.sunset-score.com/v1/api/forecast' \
  --data-urlencode 'latitude=41.8781' \
  --data-urlencode 'longitude=-87.6298' \
  --data-urlencode 'timezone=America/Chicago' \
  --data-urlencode 'days=3'

The response is JSON. Errors are printed, and requests time out after 60 seconds.

Requests share a daily allowance. A 429 response means a quota has been reached; wait for Retry-After before trying again. For a production integration or higher volume, contact us at info@sunset-score.com.

Request

GET https://api.sunset-score.com/v1/api/forecast

ParameterRequiredDescription
latitudeYes Decimal degrees, from −90 to 90.
longitudeYesDecimal degrees, from −180 to 180.
timezoneNoIANA name, such as America/Chicago or Europe/Bucharest. Defaults to UTC. Use the location’s timezone for its local calendar days.
daysNo1–3 calendar days. Defaults to 3.

One location per request. Dates start today in the selected timezone, or tomorrow after today’s sunrise and sunset are over. Today’s past sunrise may still appear. Historical dates, place names, batching and extra parameters are not supported.

Response

Events are ordered by time. Each score estimates how visually impressive the sky will be. It is a quality score, not a percentage chance of a sunset.

{

  "generatedAt": "2026-10-07T12:00:00Z",
  "location": {

Reading the forecast

type is Sunrise or Sunset. timeUTC is the event time in UTC; convert it to your display timezone. score is an integer from 0 to 100. label is a lowercase description, such as great or stunning.

Working with changing weather

Scores change as forecasts update. generatedAt records when the response was produced. Polar day or night, or missing weather coverage, can produce fewer events or an empty results array. The scoring model version may change while the v1 response format stays compatible.

API limits

This API is currently for experimenting and seeing whether Sunset Score is useful for your project. We don’t have self-service billing yet, and this access isn’t ready for production use. If you’d like to use it in your product, contact us at info@sunset-score.com and we’ll work out access with you.

AllowanceInitial limit
Shared across all callers300 requests per UTC day
Per network address20 requests per UTC day
