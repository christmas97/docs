Tool scope

get_sunset_forecast accepts numeric latitude, longitude, and optional days (1–3) for a user-chosen forecast destination. For a city name, the assistant resolves an approximate public city center; the server does not geocode names. get_local_sunset_forecast uses client-shared approximate location for near-me requests. Both are read-only and return forecast data; there is no custom widget, account, payment, subscription, or alert tool.
